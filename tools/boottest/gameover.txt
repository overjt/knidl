# Boot-test input script: the game over (tools/boottest/boottest.c,
# docs/data.md 8.4).
#
# From boot with an empty save: the menus and a new game (the opening of
# tools/boottest/input.txt), the level 1 hub, then stage 1-1, where Kirby
# loses all three lives to the enemies of its first room as fast as it can
# (six hits of one health bar each, the death, the retry from the room's
# start, three times), the GAME OVER screen (game state 22: the banner, the
# eight letters, the CONTINUE / QUIT choice), the cursor moved down and up,
# CONTINUE (the score halved, three lives again), the level 1 intro scene
# and back in the hub.
#
# One step per line: "<frames> <keys>"; "repeat <n>" ... "end"; "mark" names
# the scene starting at that frame and "expect" checks a RAM cell of the
# reference there (both outside repeat blocks).  The run starts from a fresh,
# empty save, so every frame below is deterministic; the frame numbers in the
# comments are where each step starts.  Each life's block starts at the frame
# where Kirby drops into the room (the stage start or the retry), and lasts
# exactly until the next one: the game ignores the keys of its tail while
# Kirby's death plays.
#
# Frame 0-499: the boot (HAL Laboratory / Nintendo logo, the Kirby swarm)
# and the title screen.
mark boot and title screen
500 -
expect gGameState:2 == 3
# 500: START on the title -> the fade to the menu (state 4 from 814); the A
# at 804 falls in the fade.  814: the file select (three empty files)
mark file select
4 START
300 -
4 A
300 -
expect gGameState:2 == 4
expect gMenuScreen:1 == 0
# 1108: A on FILE 1 -> GAME SELECT (start game, sub-games, sound test, erase)
mark game select
4 A
300 -
expect gMenuScreen:1 == 1
# 1412: A on START GAME -> the ONE PLAYER / MULTIPLAYER pop-up
mark one player or multiplayer pop-up
10 A
300 -
expect gMenuScreen:1 == 3
# 1722: START on ONE PLAYER -> a new game: the level 1 intro scene (state
# 7, 1739-2017), then the level 1 hub (state 5, from 2018)
mark new game: level 1 intro scene and hub
10 START
478 -
expect gGameState:2 == 5
expect gLevelIndex:1 == 8
expect gPlayerLives:2 == 2
expect gPlayerHealth:2 == 48
# 2210: UP at the door of stage 1 -> stage 1-1, room 1 (Kirby drops in at
# 2240)
mark enter stage 1-1
10 UP
20 -
expect gGameState:2 == 8
expect gLevelIndex:1 == 0
expect gStageIndex:1 == 0
expect gRoomIndex:2 == 0
mark life 1: six hits
# 2240: life 1.  Walk right: the Waddle Doo on the first step beams Kirby
# (~2425); jump onto the step (three tries, so a hit-stun cannot eat the
# jump) and walk to the second step (x 537), then pace left and right on
# the raised ground: the Waddle Dee, the second Waddle Doo, the Bronto
# Burts and the Sparky that spawn there hit Kirby every 120-270 frames (96
# frames of blinking after each).  The sixth hit (~3380) empties the health
# bar; the death plays and Kirby retries from the room's start.
180 RIGHT
repeat 3
14 RIGHT+A
50 RIGHT
end
150 RIGHT
repeat 3
100 LEFT
130 RIGHT
end

mark life 1 lost: the death
expect gPlayerHealth:2 == 0
expect gPlayerLives:2 == 2
207 -
