# The boot test's input script (tools/boottest/boottest.c, docs/data.md 8.4).
#
# One step per line: "<frames> <keys>", keys "-" (none) or names joined by
# '+' (A B SELECT START RIGHT LEFT UP DOWN R L); "repeat <n>" ... "end"
# repeats a block; "mark <scene>" names the scene that starts there and
# "expect <cell> <op> <value>" checks a RAM cell of the reference there
# (a failed check fails the run: the script no longer reaches what these
# comments claim).  The run starts from a fresh, empty save (no .sav), so
# every frame below is deterministic; the frame numbers in the comments are
# where each step starts.  The script was tuned by looking at local frames of
# the reference (never committed); what it reaches is described in words.
#
# Frame 0-499: the boot (HAL Laboratory / Nintendo logo, the Kirby swarm)
# and the title screen.

# 500: START, ignored: after a completed logo the title reads keys only
# from about frame 570.  804: A leaves the title; the menu (game state 4)
# opens on the file select (three empty files) at 814.  (Until #168 these
# comments put each screen one key early; #168's scripts found it.)
