# Boot-test input script: the three sub-games in single-player mode
# (tools/boottest/boottest.c, docs/data.md 8.4; issue #168).
#
# From boot with an empty save: START skips the boot logo, the title, A on
# FILE 1 (a new file), SUB-GAMES, then each sub-game against the computer
# (menu screen 4 row 0-2, screen 5 "1 player", the state-13 title, level 1):
#   Quick Draw   one round won (A when the "!" shows), one lost (no press),
#                the results, QUIT;
#   Bomb Rally   Kirby serves and returns the bomb until the three computer
#                players are blown up (three rounds): Kirby wins, QUIT;
#   Air Grind    A held on the rails and released over the ten gaps:
#                Kirby finishes 1st, QUIT.
# Each quit returns to the mode list with the cursor on that sub-game.
# One step per line: "<frames> <keys>"; mark/expect lines name the scenes
# and check them on the reference.  Frame numbers in the comments are where
# each step starts.  Timings were tuned on local frames and RAM peeks of the
# reference (never committed); the press windows are what the game accepts,
# found by search, so they are tight on purpose.  RAM cells: gTasks+0x2384 is
# gTasks[63].state (the sub-game controller, gSubGameTaskIdx == 63) and
# gTasks+0x2398 its Task.unk28; 0x02007FCC is gUnk_02007FCC (the sub-game
# index), 0x0200B048 gUnk_0200B048 (Quick Draw's opponent index);
# gAirGrind+4 is M37Game.raceTimes[] and gAirGrind+0x24 players[0].unk08
# (the crash penalty timer).
#
